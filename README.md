# 心动日常 · Heartfelt Days

适合手机竖屏的生活陪伴小游戏。当前包含 9 位 19 岁成年虚构伙伴、4 个生活场景、1632 个透明动作帧、独立前景视差，以及聊天、礼物、合拍挑战和回忆收集。

## 开始玩

公网访问地址：**https://ai-love-changqiye.new-dell-7068.chatgpt.site/**。采用托管 HTTPS 地址，手机直接竖屏打开；不依赖本机持续开机。


双击本目录的 **启动游戏.cmd**，打开 **http://localhost:5173/**。美术设定集：**http://localhost:5173/artbook.html**。电脑上也可打开 **http://localhost:5173/phone-preview.html**，以小屏、标准、大屏三种竖屏尺寸体验。

手机与电脑连接同一局域网后，使用启动窗口显示的 Network 地址进入。此次本机地址为 **http://192.168.0.107:5173/**；网络地址变化时以启动窗口为准。关闭启动窗口会停止预览，浏览器保存的进度仍保留。

## 一起生活

- 轻触角色，听她打个招呼；「动作」里可选择待机、散步、坐下、招手、舒展、整理发梢。原来的三位插画伙伴保留原有四组动作。
- 「跳舞」提供轻快律动、月光摇摆、日落舞步、轻盈曳步、爵士摇摆、花间圆舞。六位 CG 的原版与低领版各有六套编舞，每组 18 个独立动作帧；既可自由欣赏并手动结束，也可玩「一起合拍」。
- 合拍挑战分别使用 600、850、500、480、550、750 毫秒节拍和 16、12、20、24、20、16 拍。圆环收拢时点心形，电脑可按空格；舞蹈动画以原来的一半速度播放，每段 18 帧舞蹈在四个节拍内循环，合拍判定时机保持不变。游戏与设定集的舞蹈均使用半速基准。
- 散步、坐下及小动作完成后获得心意；坐下结束会保留坐姿。切换角色、服装或地点时结束未完成活动，完成后才发放奖励。
- 聊天支持自由输入与主题选项，各人有独立文案、喜好、聊天记录与好感度。
- 送礼消耗心意；送中喜好有额外提升。完成三种不同日常活动可领取每日 25 心意。
- 每人每个地点首次完成活动收藏一张回忆，共 36 张。

场景包括樱花公园、阳光客厅、黄昏卧室、雨天书房；含独立植物前景、花瓣或雨丝、触地阴影、座椅和夜色层。音乐默认关闭，可开启环境音乐或减少环境动态。

## 存档与对话

进度保存在当前浏览器；不同设备、浏览器及访问地址各有独立存档。「设置」提供 JSON 导出、导入，以及可复制的存档文字备份与恢复。原版三人存档会自动补齐新人物与换装数据，保留原有心意、好感、聊天和回忆。

默认为**本地剧情模式**，使用角色文案和主题识别，全部玩法无需密钥即可体验。

可选真实 AI：复制 `.env.example` 为 `.env.local`，填写 `AI_API_KEY`、`AI_BASE_URL`、`AI_MODEL` 后重启。支持 OpenAI-compatible Chat Completions；基础路径须包括服务要求的 `/v1`，不要附加 `/chat/completions`。启用后最近 12 条对话发送至配置的服务，密钥由本地服务器读取。连接失败时明确提示并回退到本地剧情。本次没有配置密钥，未验证外部模型联通。

## 美术与动画

美术设定集可切换两套服装、查看高清立绘、播放十二组动作、暂停或逐帧查看、调节速度、切换场景和透明背景，并下载 PNG 原图。

- `public/assets/cg/<人物>/`：原版高清立绘和 everyday、moments、gestures、dances 四张透明图集。
- `public/assets/cg/<人物>/low/`：新增低领版的独立立绘与完整图集。
- 上述两套服装各自的 `motion-v3/`：六种 18 帧舞蹈，PNG 原图和无损 WebP，共 72 张图集、1296 个独立舞蹈帧。旧 `dances` 图集保留作为素材备份，游戏使用新版。
- `public/assets/characters/`：三位插画伙伴的现有 48 帧素材。
- `public/assets/scenes/` 与 `public/assets/layers/`：四张场景及透明前景。
- `docs/prompts/cg/`：全部 CG 立绘、动作、换装与修正提示词。
- `docs/GAME_DESIGN.md`、`docs/CG_CHARACTERS.json`、`docs/CG_ANIMATION_PLAN.json`：制作方案与人物、动作规划。
- `docs/CG_ASSET_REPORT.json`：现有立绘与日常动作的检查记录。
- `docs/MOTION_V3_PLAN.json`、`docs/MOTION_V3_REPORT.json`：18 帧编舞规划，以及实际帧坐标、重复帧、透明背景、邻格像素与无损编码检查。
- `docs/prompts/cg/motion-v3/`：72 组新图集的实际制作提示词与修正记录。
- `docs/QA.md`、`screenshots/`：验收记录与实测截图。

全部新素材使用 Codex 内置 imagegen 制作，要求真实透明 alpha；原图保留在项目。工具不暴露模型版本选择参数，未将素材标注为指定的 image 2.5。

六位 CG × 两套服装 ×（24 个日常帧 + 6 种舞蹈 × 18 帧）= **1584 个 CG 动作帧**，另有 12 张高清立绘；加上原插画伙伴 48 帧，游戏当前共 **1632 个动作帧**。待机、行走、坐下、招手、舒展、发梢仍为原有各 4 帧，这次扩展的是全部舞蹈。72 张新舞蹈 PNG 共约 147.29 MiB，运行时无损 WebP 约 **68.97 MiB**，逐像素确认 alpha 与 PNG 相同。游戏按角色和服装加载，仅保留最近两套造型的纹理，避免切换多人时持续占用显存。

每张图集按实际透明轮廓切帧，同组固定缩放与落脚基线，不拉伸人物；设定集可从第 1 帧逐帧查看至第 18 帧。实际 CG 舞蹈播放约 5.3–9.4 帧/秒，为原速度的一半，跟随节拍循环；场景渲染目标为 60 帧/秒。生成式逐帧动画仍有轻微面容、衣料细节变化，属于多帧动画方案。

## 开发

本机使用 Node.js 24、TypeScript、Vite 7、Phaser 3.90 和 Lucide。启动和构建：

```powershell
npm install
npm run dev
npm test
npm run build
npm run preview
```

构建预览地址为 http://localhost:4173。游戏与设定集均包含在 `dist`；需通过服务器访问。静态托管支持本地剧情，真实 AI 需要对应服务端接口。当前公网版使用本地剧情模式。

修改素材后重新验证：

```powershell
node scripts/inspect-cg.mjs
node scripts/check-frame-isolation.mjs
node scripts/inspect-motion.mjs
node scripts/check-runtime-assets.mjs
# 静态发布版不包含重复 PNG，检查全部运行时素材：
node scripts/check-runtime-assets.mjs http://localhost:4173 --runtime-only
```

原 CG 检查涵盖现有 48 张图集；新增舞蹈使用 `inspect-motion.mjs` 检查 72 张图集的 1296 个独立帧、重复图片、画面边缘裁切、邻帧像素和无损 alpha，全部通过后才生成运行时清单。素材访问检查同时覆盖运行时图片和可下载 PNG。三位插画素材使用独立检查程序。制作参考：[Phaser 动画](https://docs.phaser.io/phaser/concepts/animations)、[屏幕适配](https://docs.phaser.io/phaser/concepts/scale-manager)、[Vite](https://vite.dev/guide/)。

## 公网发布

Sites 身份与静态目录配置位于 `.openai/hosting.json`。正式构建保留全部运行时无损 WebP，原始 PNG 保留在 `public/assets/` 与 GitHub 仓库；为了符合托管发布包 256 MiB 上限，构建输出不重复包含原始 PNG。设定集的下载按钮按完整图像尺寸在浏览器导出透明 PNG，无需额外图片服务器。

修改后运行 `npm run build`，再使用 Sites 发布流程保存版本并部署。`.sites-runtime/` 是被忽略的本地发布临时目录。浏览器进度按访问地址独立保存，需要迁移本机进度时可在设置里导出并导入。
